### Hey, I’m Hozaifa 👋

I’m a software developer based in Egypt, building **useful web and desktop products** with care for the details people actually notice: clear interfaces, intuitive workflows, thoughtful localization and reliable everyday use.

My work focuses on **Arabic-first UX**, multilingual experiences, privacy-conscious browser tools and offline-capable desktop software. I bring software development and language studies together to make products feel natural to their users.

> **Design the experience. Build the product. Keep it useful.**
