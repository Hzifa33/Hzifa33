<a id="about"></a>
### A little about me

I’m **Hozaifa Abozaid** (`@Hzifa33`), a software developer based in Egypt. I design and build products with an emphasis on **clear interfaces, privacy, localization, and dependable everyday workflows**. My background in language studies and customer-facing work shapes the way I think about usability: good software should make sense to the people using it.

**What I care about:** Arabic-first experiences that get RTL right · multilingual web products · offline-capable tools · thoughtful open-source software.
